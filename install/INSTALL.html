A more personal shelf.

Your extension is ready. Finish these steps in Chrome, then connect your own Douban account.

1. Open Chrome’s extensions page

Paste this address into Chrome’s address bar. Turn on Developer mode at the top right.

2. Load the extension

Click Load unpacked and select this folder:

On macOS, press ⌘⇧G in the folder picker and paste the path. On Windows, paste it into the folder picker’s address bar. If you opened this guide directly from the download, choose its extension folder.

3. Connect your own Douban history

  1. Pin Books & Movies using Chrome’s puzzle-piece menu and open it.
  2. Click Connect Douban. Complete sign-in on Douban, then return to the extension.
  3. Allow local use of your history and click Use my history. Keep the Douban tabs open until reading finishes.
  4. Click Start discovering. Interested saves a title; Skip shows the next one.

If Douban asks for verification, complete it yourself on Douban and retry. Previously read records are kept.

No local server, API key or command-line tools are needed. Keep the installed folder. Future updates require downloading the new release, running the helper again and clicking Reload in Chrome.

This GitHub build uses Chrome’s developer mode. Chrome’s final confirmation cannot be automated; direct “Add to Chrome” installation requires a Chrome Web Store listing. This project is not currently listed there.
